#   - requirements-windows10-cpu.txt

#   - requirements-windows11-cuda.txt  THIS FILE: Windows 11 + NVIDIA CUDA

# Proven Windows environment (RTX 4060 Laptop, CUDA Toolkit 13.2, MSVC 14.51):
#   Python 3.13, torch 2.12.1+cu132, torchvision 0.27.1+cu132,
#   transformers 4.50.3, ultralytics 8.4.90.
# See WINDOWS_GPU_SETUP_HANDOFF.md for the full desktop setup and the
# GroundingDINO build steps.
#
# WHY THE +cuXXX PINS AND THE EXTRA INDEX: pinning the torch stack to explicit
# CUDA local versions (and adding the PyTorch CUDA wheel index) forces pip to
# install the GPU wheels. Without it, pip and its dependents (ultralytics,
# diffusers, ...) silently pull the CPU build or a mismatched torchvision, and
# CUDA acceleration is lost. The exact "+cu132" pins only exist on the PyTorch
# index, so they cannot be satisfied by a wrong wheel from PyPI.
#
# INSTALL (PowerShell), from the repo root, inside your venv:
#   pip install --upgrade pip
#   pip uninstall -y torch torchvision torchaudio        # clear any CPU build first
#   pip install -r requirements-windows11-cuda.txt
#   pip install wheel setuptools ninja
#   pip install --no-build-isolation -e "autoannotate study/GroundingDINO"
#
# PREREQUISITES: NVIDIA driver, CUDA Toolkit 13.2, and Visual Studio Build Tools
# with the "Desktop development with C++" workload. See HOW_TO_RUN.txt STEP 0.
#
# If using another CUDA version, first choose a torch/torchvision pair that
# actually exists in PyTorch's official wheel index, change both pins and the
# index URL together, install the matching CUDA Toolkit, and rebuild
# GroundingDINO. Do not change only the "cu132" text and assume compatibility.
#
# For a fully reproducible snapshot of your exact machine, after a working
# install (this creates a separate snapshot; do not replace this install file):
#   pip freeze > requirements-windows11-cuda.freeze.txt
