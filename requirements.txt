# AutoAnnotate runtime dependencies - GENERIC FLOORS (any OS).
#
# There is no one-size-fits-all install. Pick the file for your machine:
#   - requirements.txt            THIS FILE: generic floors, no upper pins.
#                                 Use only if you intentionally want the newest
#                                 resolutions and will sort out torch yourself.
#   - requirements-macos.lock     macOS / Apple Silicon (MPS): exact proven pins.
#   - requirements-windows10-cpu.txt
#                                 Windows 10 CPU-only: exact proven pins.
#   - requirements-windows11-cuda.txt  Windows 11 + NVIDIA CUDA: pinned CUDA torch
#                                 wheels so the right GPU build is installed.
#
# Floors here match what the project was developed against. Upper pins are
# avoided where possible (they over-constrain wheel resolution); the only
# exception is transformers, where 5.x breaks GroundingDINO.
#
# Windows users: use requirements-windows10-cpu.txt on a CPU-only machine or
# requirements-windows11-cuda.txt with an NVIDIA GPU. Do not use this generic file for
# either proven Windows setup.
#
# GroundingDINO is intentionally NOT listed here - it ships with its own
# setup.py under autoannotate study/GroundingDINO/. Install it after this
# file with: pip install -e "autoannotate study/GroundingDINO"

# ── Core ML stack ─────────────────────────────────────────────────────────
torch>=2.0
torchvision>=0.15
numpy>=1.24

# ── Detection / segmentation models ──────────────────────────────────────
# SAM3 requires >=8.3.237 (added in that release). YOLOE-11 stride=14 fix
# is also in this range.
#
# SAM3 box exemplars are SINGLE-CONCEPT per call on every version in this
# range: SAM3SemanticPredictor._inference_features forces `nc = 1` the moment
# `bboxes` is passed, and its `labels` array is a positive/negative exemplar
# flag, not a class id. Verified against 8.4.33 (macOS) and 8.4.90 (Windows).
# Multi-class box prompts therefore run one pass per class; see
# ManualWindow._run_sam3_boxes_multiclass. Do not "optimize" that into one call.
ultralytics>=8.3.237

# ── Vision / image I/O ───────────────────────────────────────────────────
opencv-python>=4.8
Pillow>=10.0
shapely>=2.0

# ── LLM-prompt path (SmolVLM / Florence / Gemma in AutomatedWindow) ──────
# <5 is required: transformers 5.x removed BertModel.get_head_mask, which
# GroundingDINO's BERT wrapper calls (crashes at DINO model load otherwise).
transformers>=4.40,<5
accelerate>=0.30
huggingface_hub>=0.20

# ── Stable Diffusion synthetic image generation ──────────────────────────
# Drives the "Generate Variation" / "Variations for Folder" flow in
# ManualWindow. 0.27 is the floor where StableDiffusionInpaintPipeline
# stabilized for SD-2 inpainting; older versions miss the use_safetensors
# kwarg or have noisier MPS code paths.
diffusers>=0.27

# ── GUI ───────────────────────────────────────────────────────────────────
PyQt5>=5.15

# ── Config / env ─────────────────────────────────────────────────────────
python-dotenv>=1.0
